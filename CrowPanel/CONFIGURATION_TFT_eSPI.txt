Dans la bibliotheque TFT_eSPI, User_Setup.h doit contenir cette configuration
pour le CrowPanel Elecrow 3,5 pouces V2.2 / DIS05035H :

#define USER_SETUP_INFO "PonyGotchi CrowPanel V2.2"
#define ILI9488_DRIVER
#define TFT_WIDTH 320
#define TFT_HEIGHT 480
#define TFT_MISO 33
#define TFT_MOSI 13
#define TFT_SCLK 14
#define TFT_CS 15
#define TFT_DC 2
#define TFT_RST -1
#define TFT_BL 27
#define TFT_BACKLIGHT_ON HIGH
#define TOUCH_CS 12
#define LOAD_GLCD
#define LOAD_FONT2
#define LOAD_FONT4
#define LOAD_FONT6
#define LOAD_GFXFF
#define SPI_FREQUENCY 27000000
#define SPI_READ_FREQUENCY 16000000
#define SPI_TOUCH_FREQUENCY 2500000

La microSD est reliee sur un autre SPI (HSPI) :
CS=5, SCK=18, MISO=19, MOSI=23.

Sous Arduino IDE 2.x : Board > ESP32 Dev Module, activer PSRAM dans Tools
si l'option est proposee; selectionner le port COM du CrowPanel.
Ne pas remplacer User_Setup.h si la version precedente de PonyGotchi fonctionne deja.
