# Ouvre ce fichier en premier dans Codex

1. Lis `AGENTS.md` et `docs/CAHIER_DES_CHARGES_V08.md`.
2. Regarde les DEUX images dans `assets/references/`.
3. Démarre le jeu avec `npm run dev` et visite `http://127.0.0.1:4173/`, ou ouvre `preview-offline.html`.
4. Lance `npm test`, puis exécute `python scripts/build_preview.py` après tes changements.
5. Copie le texte de `docs/PROMPT_CODEX.md` comme premier message dans Codex.

**Attention à la direction artistique :** au repos, aucun HUD. Au toucher, un panneau très compact à cœurs + actions inspiré de la deuxième image utilisateur. Le poney doit se déplacer dans le décor.
