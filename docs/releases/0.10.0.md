## Reproduire sous Linux x86_64

Python 3.12, Git et compilateur C++ hôte nécessaires. Depuis la racine :

```sh
python3 -m venv .build/venv
.build/venv/bin/pip install -r firmware/requirements-build.txt
.build/venv/bin/python scripts/bootstrap_toolchain.py --destination /tmp/pony-toolchain
PATH="$PWD/.build/venv/bin:$PATH" .build/venv/bin/python scripts/build_firmware.py --toolchain /tmp/pony-toolchain
.build/venv/bin/python scripts/convert_firmware_assets.py
python3 scripts/build_preview.py
.build/venv/bin/python scripts/package_release.py /tmp/pony-toolchain/arduino-user/hardware/espressif/esp32
```

Le bootstrap vérifie les digests officiels verrouillés dans `firmware/toolchain-lock.json`. Il n'écrase pas un répertoire d'installation existant non reconnu. Les sources manuelles correspondent aux mêmes core/toolchain que Boards Manager ; la chaîne est figée et reconstructible, sans revendiquer un ZIP reproductible octet pour octet (timestamps et logs contiennent des chemins locaux).

Le paquet contient la preview, le firmware fusionné à flasher à l'adresse 0, les assets SD, les sources, les SHA256 et la [procédure Windows](../INSTALL_WINDOWS.md). Les scripts Windows sont **non exécutés sous Windows**. Aucun flash USB, essai matériel ni test de la future CI GitHub n'a été effectué ici.

Les captures `docs/preview_lockscreen.png` et `docs/preview_hud.png` sont des preuves du navigateur **320×480**, pas des photos du TFT.
